# Angular boilerplate

An Angular starter for [Wodby](https://wodby.com), generated with the Angular CLI and configured for static deployment.

## Local development

```sh
npm install
npm start
```

Open <http://localhost:4200>.

## Production build

```sh
npm run build
```

The static application is written to `dist/angular-boilerplate/browser`. The included Wodby CI pipeline builds and publishes that directory. This boilerplate is used by the [Angular service](https://github.com/wodby/service-angular) and [Angular stack](https://github.com/wodby/stack-angular).
